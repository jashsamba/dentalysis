## What it does

- **Finds jobs.** Scrapes Indeed with Playwright.
- **Ranks them.** Claude scores each listing against the resume.
- **Writes cover letters.** Generates a tailored PDF cover letter for each application.
- **Tracks everything.** Every application is stored in Supabase behind a React dashboard.

One idea worth calling out: the cover letters openly disclose that AI helped write them. The tool itself becomes a demonstration of the skills being applied for.
